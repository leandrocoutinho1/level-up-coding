# Level Up Coding


> Projeto para consolidar conhecimento em Engenharia de Software e evoluir de Desenvolvedor Júnior para Pleno.  
> PHP é a ferramenta utilizada, mas o foco é na prática de estruturas de dados, algoritmos e boas práticas de engenharia.

---

## Objetivo

- Praticar **estruturas de dados** clássicas (Stack, Queue, HashMap, etc.)  
- Implementar **soluções eficientes** e **código limpo**  
- Consolidar **conceitos de engenharia de software**, incluindo tipagem, contratos, exceções e design de código  
- Criar um **portfólio sólido**, aplicável a qualquer outra linguagem
